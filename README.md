# 抽取座号 · Seat Draw Ball

Windows 桌面悬浮小工具：一个透明圆形小球停在桌面角落，**单击即抽取一个座号**，结果显示在球上；右键弹出菜单可调人数、锁定位置、置顶、开机自启、重置。

> 适用于课堂点名、会议抽号、抽奖等场景。绿色便携，无需安装。

## 功能特性

- **单击抽号**：滚动动画后落定，号码直接显示在球上，球下方显示剩余数量
- **人数可调**：菜单里 `− / 输入 / ＋` 调整总人数（默认 80），调整后自动排除超范围记录
- **锁定位置**：开启后小球贴屏幕右下角固定，重启保持位置，拖拽完全禁用；关闭后恢复自由拖动
- **始终置顶**：小球浮在其他窗口之上
- **开机自启**：默认开启，可在菜单中关闭
- **重置记录**：清空已抽记录，保留人数设置
- **位置记忆**：关闭后重新打开，回到上次位置
- **真随机**：使用系统级 CSPRNG（`crypto.getRandomValues`），并做相邻去重，避免"开头总是那几个号"
- **无阴影干净外观**：透明窗口 + 圆形裁剪 + 无任何外部投影

## 使用方法

1. 下载对应系统的 `.exe`（教学版为安装包或绿色压缩包）
2. 双击运行。首次运行 Windows 可能提示"SmartScreen 已阻止"，点 **更多信息 → 仍要运行**
3. 小球出现在屏幕角落：
   - **单击小球**：抽取一个座号
   - **右键小球**：打开菜单（人数、锁定位置、置顶、开机自启、重置）
   - **按住拖动**：移动小球位置（锁定状态下禁用）
4. 关闭：右键菜单里退出，或任务栏结束进程

## 技术说明

- 基于 Electron，主进程创建两个透明无边框窗口：小球窗（136×136，圆形裁剪 72 段）与菜单窗（220×360）
- `hasShadow: false` 关闭系统阴影；Windows 下加 `disable-direct-composition` 保证 `setShape` 圆形裁剪生效
- CSS 层不使用任何外部 `box-shadow`，球外零投影
- 数据保存在 `localStorage`（键 `seat-draw-ball-v1`）：人数、已抽记录、位置、锁定、置顶、自启状态
- 打包：Windows x64 / ARM64 使用 [warp](https://github.com/electron/warp) 单文件打包；32 位教学版使用 NSIS 安装包 + PowerShell 自检补丁脚本
